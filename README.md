# Midnight Vibes Radio Website

## Project Overview
This project is a multi-page HTML website for a radio station called **Midnight Vibes Radio**. The website was created to practice basic web design skills such as page structure, semantic HTML, navigation, linking pages together, and organizing content across multiple pages.

## Purpose
The main goal of this project was to build a complete website using HTML while keeping the design simple, clear, and easy to navigate. It also gave me practice using inline CSS to style each page with a consistent black and purple color scheme.

## Pages Included

### Home Page
The Home page introduces the station and includes:
- The station name
- A tagline
- A welcome section
- A short description of the station
- A featured “Now Playing” section
- A moving banner to show live or current music information
- Links to other pages on the site

### Schedule Page
The Schedule page shows the daily and featured programming for the station. It gives visitors an idea of when different shows are on and helps organize the radio station content clearly.

### About Page
The About page explains:
- The story of the radio station
- The type of music it plays
- The station’s mission
- What makes the station unique

### Contact Page
The Contact page includes:
- Phone number
- Email
- Social media information
- Hours and location
- A contact form with:
  - Name
  - Email
  - Message
  - Submit button

## Features
Some features included in this project are:
- Multi-page website layout
- Consistent navigation bar on every page
- Black and purple color scheme
- Inline CSS styling
- Contact form
- Featured show sections
- Moving “Now Playing” banner for a more interactive look

## HTML Elements Practiced
This project helped me practice using:
- `<!DOCTYPE html>`
- `<html>`, `<head>`, and `<body>`
- `<header>`, `<nav>`, `<main>`, and `<footer>`
- Headings and paragraphs
- Links with `<a>` tags
- Forms with `<form>`, `<input>`, `<textarea>`, and `<button>`
- Sections and content boxes with `<section>` and `<div>`

## What I Learned
This project helped me get more comfortable building a full website with multiple pages. I practiced organizing content, creating working navigation, styling pages with inline CSS, and adding a moving banner feature to make the website feel more interactive. Overall, this project helped me improve my confidence with basic HTML and webpage structure.
